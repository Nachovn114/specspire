# Fase 6 · Entregar

**Resultado:** otra persona puede ejecutar, demostrar y mantener la aplicación.

1. Crea/actualiza el `README.md` **del producto**: propósito, requisitos de entorno, instalación, ejecución, tests, limitaciones y ejemplos breves.
2. Si lo pide el proyecto: prepara build/deploy, configuraciones seguras, logs y paso de rollback verificable; no publiques credenciales.
3. Si es académico: entrega solo artefactos y capturas verídicas de la rúbrica. Conserva decisiones y trazabilidad.
4. Revisa `git diff`, estado de pruebas, cobertura de requisitos y riesgos conocidos. Una revisión independiente es preferible para cambios relevantes.
5. Documenta `cómo reproducir` y `qué falta`; deja el código en estado limpio. No afirmes despliegue si no ocurrió.

**Gate:** README probado por un tercero o siguiendo sus pasos; entrega validada para el alcance actual.

**Prompt:** «Prepara la entrega sin inventar evidencias: README, comandos validados, requisitos completados y pendientes. Solo despliega si está solicitado».
