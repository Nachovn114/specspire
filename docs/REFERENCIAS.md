# Fuentes de inspiración y atribuciones

Consulta del 31 de octubre de 2026. Specspire implementa procedimientos propios y **no redistribuye Skills ajenas**.

| Proyecto | Aprendizaje aplicado | Límite deliberado |
|---|---|---|
| [GitHub Spec Kit](https://github.com/github/spec-kit) | Especificación → plan → tareas → implementación → convergencia | No copiar comandos ni duplicar `.specify/` |
| [Matt Pocock Skills](https://github.com/mattpocock/skills) | Aclarar necesidades, glosario, módulos bien diseñados, TDD y review | No instalar el catálogo completo por defecto |
| [Superpowers](https://github.com/obra/superpowers) | Red-Green-Refactor, depuración basada en hipótesis y evidencia | No exigir subagentes siempre |
| [OpenSpec](https://github.com/Fission-AI/OpenSpec) | Documentación por intención y cambios pequeños | No generar burocracia adicional |
| [BMAD Method](https://github.com/bmad-code-org/BMAD-METHOD) | Adaptar el proceso al tamaño del trabajo | No imponer roles o ceremonias a formularios simples |
| [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | Tokens, tipografía, responsive, accesibilidad y validación visual | No copiar el catálogo ni agregar dependencias por defecto |
